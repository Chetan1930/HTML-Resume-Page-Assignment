# 🧾 HTML Resume Page Assignment

This project is a **simple, clean, and responsive HTML Resume Page** created as part of an HTML learning assignment.
It demonstrates proper use of **semantic HTML elements**, tables, lists, and basic styling to build a professional resume layout.

🔗 **Live Demo:**
👉 [https://chetan1930.github.io/HTML-Resume-Page-Assignment/](https://chetan1930.github.io/HTML-Resume-Page-Assignment/)

---

## 📌 Features

* Semantic HTML structure (`header`, `section`, `footer`)
* Professional resume layout
* Skills section using lists
* Experience & Education displayed using tables
* Projects section with bullet points
* Clean and readable design
* Hosted using **GitHub Pages**

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **GitHub Pages** (for deployment)
